## ADDED Requirements

### Requirement: 证据记录可追溯

每条对照记录必须写明官方文件和行号范围、Python 代码位置、测试名称、输入条件、关键输出和退出状态。记录使用中文说明，代码、命令、路径和标识符保留原文。

#### 场景：新增或修正规则

- **当** 规则代码发生变化
- **那么** 必须同时更新对照矩阵、验收清单和对应测试
- **并且** 测试必须直接检查阶段、角色、阵营、存活、恋人、死因、胜负或事件元数据等结果字段

### Requirement: 区分玩法与平台

官方玩法规则、QQ 指令映射和 QQ 平台菜单显示必须分开记录。QQ 菜单接口失败不能被算作玩法规则通过；同样，QQ 没有 Telegram 按钮也不能被算作核心规则差异。

#### 场景：QQ 平台差异

- **当** 某项只影响菜单、消息格式或按钮展示
- **那么** 将其标为平台适配项
- **并且** 不改变核心规则对照的通过条件
