## Purpose

把 Telegram 版的按钮、私聊、群聊和分步操作转换成 QQ 中清楚可用的交互，让玩家不需要猜测下一步该发什么内容。

## ADDED Requirements

### Requirement: QQ 指令和菜单入口
系统 MUST 在 QQ 群聊和私聊中提供官方流程所需的指令入口，并在帮助、菜单或错误提示中显示当前可用指令。

#### Scenario: 玩家查看当前操作
- **WHEN** 玩家发送帮助、菜单或当前阶段不支持的指令
- **THEN** 系统返回与其会话和阶段匹配的可用操作列表

#### Scenario: 指令缺少前置条件
- **WHEN** 玩家发送需要房间、身份或私聊上下文的指令但条件未满足
- **THEN** 系统明确提示正确的官方指令入口，不要求玩家使用无法被机器人识别的自然语言替代词

### Requirement: 分步行动交互
系统 MUST 将官方按钮式或多步式行动转换为 QQ 可完成的逐步选择，并支持取消、重选、确认和超时。

#### Scenario: 开始多步选择
- **WHEN** 玩家触发需要多个目标的行动
- **THEN** 系统逐步发送目标选项，并标明当前正在选择第几项

#### Scenario: 取消或重选行动
- **WHEN** 玩家在确认前发送取消或重选
- **THEN** 系统撤销未提交的选择并回到官方允许的选择步骤

#### Scenario: 私聊身份操作
- **WHEN** 身份行动需要保密且玩家通过私聊操作
- **THEN** 系统只在该玩家的私聊中接收和反馈行动，群聊只显示官方允许的公开结果

### Requirement: 连接与消息失败反馈
系统 MUST 在 QQ Gateway 连接、消息发送和会话识别异常时给出可理解的状态反馈，并避免把已确认的行动重复执行。

#### Scenario: 机器人已连接
- **WHEN** Gateway 成功连接并完成指令注册
- **THEN** 机器人可接收群聊和私聊指令，并展示已启用的官方入口

#### Scenario: 消息暂时失败
- **WHEN** QQ 平台暂时拒绝或延迟处理消息
- **THEN** 系统记录失败、返回简短重试提示，并保持游戏状态可恢复
