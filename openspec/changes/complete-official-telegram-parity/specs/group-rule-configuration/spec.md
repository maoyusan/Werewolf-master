## Purpose

让每个 QQ 群分别保存和使用官方规则设置，使不同群可以稳定地使用自己的身份池、计时和公开信息规则。

## ADDED Requirements

### Requirement: 群级规则设置
系统 MUST 按群保存官方支持的身份池、人数限制、阶段计时、死亡身份显示、投票方式、特殊身份开关和其他官方可配置项。

#### Scenario: 设置群规则
- **WHEN** 具备管理权限的用户修改一项官方规则
- **THEN** 系统校验取值、保存到该群，并在下一局或官方规定的时点生效

#### Scenario: 多群相互隔离
- **WHEN** 两个群使用不同的规则设置并同时开局
- **THEN** 每局只读取所属群的设置，任何一个群的修改都不影响另一个群

### Requirement: 配置查看和错误处理
系统 MUST 提供查看当前群配置的官方入口，并对无权限、未知设置、非法取值和游戏中修改给出明确结果。

#### Scenario: 查看当前配置
- **WHEN** 群成员请求群配置
- **THEN** 系统只返回该群当前有效的官方配置

#### Scenario: 修改配置失败
- **WHEN** 普通成员或用户提交非法配置
- **THEN** 系统拒绝修改并说明原因，原配置保持不变

### Requirement: 配置持久化和兼容
系统 MUST 在容器重启后恢复群配置和进行中的必要阶段状态，并兼容已有数据和现有启动方式。

#### Scenario: 容器重启
- **WHEN** QQ 服务容器重启
- **THEN** 群配置仍可读取，已结束的游戏不会被错误恢复为进行中

#### Scenario: 旧数据升级
- **WHEN** 使用现有数据库启动新版本
- **THEN** 系统完成必要的默认值补齐，不删除已有玩家、房间或群数据
