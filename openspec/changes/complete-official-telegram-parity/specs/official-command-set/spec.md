## Purpose

补齐 Telegram 官方实际提供的辅助命令、参数、帮助和状态信息，并在 QQ 中给出一致且可发现的入口。

## ADDED Requirements

### Requirement: 官方辅助命令
系统 MUST 提供官方版本实际支持的玩家列表、身份列表、群列表、下一局、语言、状态、版本、变更记录和帮助类命令，并保持对应的前置条件和结果。

#### Scenario: 查询辅助信息
- **WHEN** 玩家发送合法的辅助命令
- **THEN** 系统在当前会话返回对应官方格式的信息，不改变游戏状态

#### Scenario: 语言设置
- **WHEN** 用户查看或修改支持的语言
- **THEN** 系统按官方规则保存语言范围，并使用该语言返回后续提示

### Requirement: 命令参数和权限
系统 MUST 校验命令参数、会话范围和管理权限，并在错误时给出正确用法。

#### Scenario: 参数错误
- **WHEN** 命令缺少参数、参数格式不对或使用未知参数
- **THEN** 系统返回该命令的官方用法，不执行部分修改

#### Scenario: 权限不足
- **WHEN** 没有权限的用户执行管理命令
- **THEN** 系统拒绝操作并说明需要的权限，不泄露或修改群配置

### Requirement: 指令可发现性
系统 MUST 将已启用的官方命令注册到 QQ 指令菜单，并让帮助内容、错误提示和菜单名称保持一致。

#### Scenario: 指令注册
- **WHEN** 服务启动并成功连接 QQ Gateway
- **THEN** QQ 指令菜单包含所有已启用官方命令及简短说明

#### Scenario: 注册失败
- **WHEN** 指令菜单更新失败
- **THEN** 系统记录失败并保留消息指令处理，同时在状态信息中标明菜单未同步
