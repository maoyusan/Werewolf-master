# 狼人杀游玩教程（QQ 机器人版）

本教程按照真实一局的先后顺序，从建房一直讲到结算，并逐条说明**你要在什么时候、在哪里（群里还是私聊）、发送什么指令**。

内容全部按本项目的实际实现书写，规则基线是官方 `Werewolf for Telegram`（提交 `ca547ccb0ed01e6f282f9e8e71f7a24d547b24d7`）。文中出现的每一句提示语、每一个时长、每一个判定条件，都来自本仓库 `domain/engine.py`、`domain/rules.py`、`application/service.py` 的当前代码。

> 如果你从没玩过狼人杀：直接从「零、一分钟看懂狼人杀」开始读，然后照着「二、完整流程」走一遍就会了。

---

## 零、一分钟看懂狼人杀

- 所有人被暗中分成几个阵营，最常见的是**村民阵营**和**狼人阵营**。除此之外还有连环杀手、纵火犯、教会等独立阵营。
- 游戏在「**夜晚**」和「**白天**」之间循环。
- **夜晚**：大家「闭眼」。有夜间技能的人私聊机器人偷偷行动——狼人挑一个人杀掉，预言家查一个人的身份，守卫保一个人，等等。
- **白天**：机器人公布昨夜的死讯。活着的人在群里自由讨论、推理、互相怀疑。
- **投票**：讨论结束后大家投票，票最多的人被「处决」出局。
- 然后又是夜晚，如此循环，直到某个阵营达成胜利条件。
- 村民阵营的胜利条件是**杀光所有狼人和其它敌对角色**；狼人阵营的胜利条件是**狼人数量 ≥ 其他所有人数量**。

你唯一需要记住的核心：**夜晚私聊机器人行动，白天在群里说话和投票。**

## 一、开始之前

### 1.1 两个说话的地方

| 场合 | 做什么 |
|------|--------|
| **QQ 群里** | 建房、加入、开局、查看进度、白天投票 |
| **私聊机器人** | 接收身份、夜晚行动、白天的技能行动、查看自己的身份 |

发错地方机器人会直接告诉你：

- 在私聊发群指令 → 「该命令请在群里发送」
- 在群里发夜间行动 → 「夜间行动请私聊机器人」

**重要**：夜晚行动必须私聊，在群里发出来等于当众自曝身份。

### 1.2 第一次玩：先加机器人为好友

机器人是一个普通 QQ 号（由 NapCat 登录），**不需要任何绑定、关联码或额外注册**。
群里发指令时它就知道你是谁，私聊也用同一个 QQ 号，两边天然对得上。

唯一要做的事：**把机器人加成好友**，否则它发不出私聊，你收不到身份牌。加过一次
就永久有效。

另外，如果机器人在群里是**管理员**，开局时它会自动把每个参赛玩家的群名片改成
「1号」「2号」……，出局后改成「3号（已出局）」。这样群里谁是几号、谁还活着，
看名片就一目了然。机器人不是管理员时游戏照常进行，只是不改名片。

### 1.3 指令怎么写

三种写法都可以，效果完全一样：

```
/join
join
加入
```

也就是说：**斜杠可加可不加，中文别名和英文别名等价**。指令直接发在群里就行，**不用 @ 机器人**；习惯性 @ 一下也没关系，机器人会自动去掉 @ 再识别。

### 1.4 怎么指定目标

需要选人的指令，目标可以用这几种写法（以座位 3 号的「小明」为例）：

```
狼人 3
狼人 3号
狼人 小明
```

规则：

- **默认不能选自己**（只有丘比特连线时允许把自己选进去）。
- **不能选已经出局的人**。
- 群里如果拿不到你的 QQ 昵称，机器人会用「3号」这样的座位号来称呼你，此时就用座位号指定目标。

### 1.5 不带目标发指令 = 分步选人

如果你只发指令、不带目标，机器人会列出所有可选的人让你挑：

```
你：狼人
机器人：请选择目标：
        1号 小红
        2号 小刚
        4号 阿伟
        直接回复座位号；可发送"取消"结束本次选择。
你：4
机器人：（确认并记录）
```

分步选人过程中可用的三个回复：

| 回复 | 作用 |
|------|------|
| `确认` | 确认当前选择 |
| `重选` | 清空重新选 |
| `取消` | 放弃这次行动 |

注意：**分步选择会随阶段过期**。如果你拖到天亮才回复，机器人会提示「上一项选择已经过期，请按当前阶段重新发送行动指令。」

## 二、完整流程

### 第 1 步：创建房间（群里）

任何人都可以建房，**不需要管理员权限**。

```
/startgame
```

别名：`开始游戏`、`开局`、`start`、`建局`

想开混乱模式（身份分配更随机、更刺激）就发：

```
/startchaos
```

别名：`混乱开始`

机器人会回两条：

> 房间已创建，发起人是 小明，正在等待玩家加入。

> 入场阶段剩余 180 秒，请发送 /join 参加，至少需要 5 人。人数够了以后，发起人发送 /startgame 或 /go 就能立刻开局。

**发起人（房主）**就是发出建房指令的人。房主有三个特权：直接开局、取消本局、房主离场时自动移交给下一位在场玩家。

一个群同时只能有一局。已经有房间时再发 `/startgame`，不会报错，而是变成「加入提示」或「立刻开局」（见第 3 步）。

### 第 2 步：加入游戏（群里）

其他人发送：

```
/join
```

别名：`加入`、`参加`

每有一个人加入，机器人会播报当前人数：

> 小红 加入游戏，当前 4 人。还需 1 人。

人数够了以后变成：

> 阿伟 加入游戏，当前 5 人。现在可以开始，房主发送 /startgame 立即开局。

入场阶段的其它指令：

| 指令 | 别名 | 谁能用 | 作用 |
|------|------|--------|------|
| `/leave` | `退出` `离开` | 任何在场玩家 | 退出本局 |
| `/cancel` | `取消` | 房主 / 管理员 | 解散整个房间 |
| `/status` | `状态` `玩家` `玩家列表` | 任何人 | 查看当前人数和剩余时间 |
| `/extend 30` | `延长 30` | 视群配置 | 延长入场时间（默认关闭，需管理员开启） |
| `/nextgame` | — | 任何人 | 预约下一局，开局时私聊提醒你 |

关于人数：

- **最少 5 人**（可由部署时的 `MIN_PLAYERS` 调整，本仓库 `.env` 当前设为 3，方便测试）
- **最多 35 人**（官方硬上限，不可超过）
- 人满 35 人时立刻停止等待，直接进入开局

### 第 3 步：准备与开局（群里）

本项目**没有单独的「准备 / ready」指令**——加入房间就等于准备完毕。人数够了就可以开局。

开局有三种触发方式：

**① 房主主动开局（最常用）**

```
/go
```

别名：`/forcestart`、`强制开始`、`立即开始`、`马上开始`

或者房主再发一次 `/startgame` 也是同样效果。

**② 入场时间到（180 秒）自动开局**

到点时人数够 → 自动开局；人数不够 → 机器人播报「入场时间结束，人数不足，本局已取消。」并解散房间。

**③ 人数达到 35 人上限，立即开局**

关于权限，这里说清楚：

- **房主本人可以直接开局，不需要任何管理员权限。**
- 群管理员 / 机器人管理员也可以开局（兜底通道）。
- 房主意外离场且没有接任者时，任何在场玩家都可以开局。
- 其他人尝试开局会被拒绝：「只有本局发起人（小明）或管理员可以开始游戏。」
- 人数不够时开局会被拒绝：「人数不足，至少需要 5 人，当前 3 人。」

开局成功后，群里播报：

> 游戏开始，共 8 人。第 1 夜开始，请查看私聊身份和行动提示。

### 第 4 步：身份分配（私聊）

开局瞬间，机器人给每个人**私聊**发一条身份消息，包含身份名 + 一句该身份的操作说明。例如：

> 你的身份是【预言家】。夜晚发送"查验 座位号"查看身份。

部分身份还会额外收到情报：

| 身份 | 额外私聊内容 |
|------|--------------|
| 狼人、雪狼、阿尔法狼等 | 告知同伴狼人是谁 |
| 教徒 | 告知同伴教徒是谁 |
| 石匠 | 告知另一位石匠是谁 |
| 守望者 | 告知预言家是谁 |
| 愚者 | **被告知自己是预言家**（其实不是，你的查验结果是假的） |

任何时候想再看一眼自己的身份，**私聊**发送：

```
/身份
```

别名：`角色`、`identity`、`role`

身份是**随机分配 + 官方平衡算法**生成的：先按 `人数 ÷ 5`（上限 5 个）确定狼人数量，再从全角色池抽取，最后做多轮校验（村民阵营与敌对阵营的强度差不能超过 `人数÷4+1`、公开身份类角色不超过总数 1/3、封锁类角色不超过 1/4 等），最多重试 500 次直到配平。

想看本局理论上可能出现哪些身份：

```
/rolelist
```

### 第 5 步：夜晚阶段（私聊）

每一夜开始时，有技能的人会**私聊**收到行动菜单：

> 第 1 夜可用行动：查验 目标；没有目标时发送"跳过"。

**夜晚时长：默认 90 秒。** 如果首夜有丘比特、分身、野孩子、盗贼这类必须首夜选人的角色，首夜会自动延长到至少 120 秒。

夜晚的公共规则：

- 每人每夜**只能提交一次**该行动，提交后再发会被拒绝：「该夜间行动已经提交」
- 不想行动就发 `跳过`（别名 `skip`）
- 首夜的丘比特、分身、野孩子、盗贼**必须选**，不能跳过
- 所有人都行动完毕，或时间到，夜晚立刻结算

#### 各角色的夜晚行动指令

| 身份 | 私聊发送 | 说明 |
|------|----------|------|
| 狼人 / 狼崽 / 狼人（狼族） | `狼人 3` | 袭击目标。多只狼共同投票决定杀谁 |
| 阿尔法狼 | `狼人 3` / `转化 3` | 除了袭击，还可尝试把目标转化为狼（有概率失败） |
| 雪狼 | `冻结 3` | 冻结目标，使其下一夜无法行动。不参与狼人袭击投票，但计入狼人多数 |
| 预言家 / 学徒预言家 | `查验 3` | 查看目标是不是狼人 |
| 愚者 | `查验 3` | 自以为是预言家，结果不准 |
| 神谕者 | `查验 3` | 看到的是「目标**不是**某个身份」 |
| 占卜师 | 自动 | 每夜自动看到一个本局可能存在、当前未公开的身份 |
| 守卫 | `守护 3` | 保护目标不被狼人杀死 |
| 妓女 | `访问 3` | 拜访目标。访问到狼人会死，被访问者当夜若被杀则你也会死 |
| 教徒 | `转化 3` | 把目标发展为教徒 |
| 教徒猎人 | `猎杀教徒 3` | 猎杀你认为是教徒的人。猜错会自己死 |
| 连环杀手 | `连环杀 3` | 每夜独自杀一人 |
| 纵火犯 | `纵火 3` / `引燃` | 先浇油标记，再择机一次性点燃所有已浇油的人 |
| 丘比特 | `恋人 2 5` | **仅首夜**，把两个人连成情侣。一方死另一方殉情 |
| 分身 | `模仿 3` | **仅首夜**，选一个模板；模板死亡后你继承其身份 |
| 野孩子 | `偶像 3` | **仅首夜**，选一个偶像；偶像死亡后你变成狼人 |
| 盗贼 | `盗取 3` | 记录盗取目标，有概率窃取其身份 |
| 化学家 | `化学 3` | 与目标一起服药，有概率毒死对方 |
| 掘墓人 | 自动 | 每夜自动挖掘昨夜新墓，无需发指令 |
| 巫师 | `查验 3` | 只能分辨对方是不是狼人或预言家 |

纵火犯的菜单比较特殊。第一次会是：

> 第 1 夜：你想给谁的房子浇油？发送"纵火 座位号"；不行动发送"跳过"。

已经浇过油之后变成：

> 第 2 夜：要继续给别人的房子浇油，还是点燃所有已浇油的房子？发送"纵火 座位号"浇油，发送"引燃"点火；不行动发送"跳过"。
> 你已经浇过油的房子：2号 和 5号

#### 没有夜间技能怎么办

普通村民、酒鬼、王子、市长、和平主义者等**不会收到夜晚菜单**，安心等天亮就行。

### 第 6 步：白天讨论（群里 + 私聊）

夜晚结算完毕，机器人在群里公布结果：

> 昨夜 2号 小刚 被狼人杀害。

> 第 2 天开始，讨论阶段 120 秒后进入投票。

紧接着播报存活名单。

**白天时长** = `基础 60 秒 + max((存活人数 ÷ 5 − 1) × 30, 60)` 秒。人越多，讨论时间越长。

这个阶段就是**在群里正常聊天**——分析、质疑、辩解、抱团。机器人不解析你的聊天内容，这部分是纯人和人的博弈。

同时，白天有技能的角色会**私聊**收到菜单：

| 身份 | 私聊发送 | 触发条件 | 说明 |
|------|----------|----------|------|
| 侦探 | `侦查 3` | 每天 | 讨论结束后私聊告诉你目标的身份，但有概率暴露自己 |
| 市长 | `市长` | 仅第 1 天 | 公开身份，之后你的投票记两票 |
| 和平主义者 | `和平` | 仅第 1 天 | 发表演说，**直接阻止本轮处决** |
| 沙人 | `催眠 是` | 一次性 | 今晚让所有人入睡，全部夜间行动暂停 |
| 铁匠 | `撒银 是` | 一次性 | 撒银粉，今夜狼人无法袭击 |
| 枪手 | `开枪 3` | 有子弹时 | 当场打死目标，菜单会显示剩余子弹数 |
| 南瓜 | `开枪 3` | 每天 | 引爆自己，与目标同归于尽 |
| 捣乱者 | `捣乱` | 一次性 | 本轮进行**双重处决**，出局两个人 |

注意：`市长`、`和平`、`催眠`、`撒银`、`捣乱`这几个不需要选目标，直接发指令即可（分步流程里回复「确认」也行）。

其中「市长」和「和平」按下后会**公开点名**，例如：

> 小红 已公开市长身份，投票权重提升。

> 阿伟 撒下银粉，本夜狼人袭击会被阻断。

### 第 7 步：投票处决（群里）

讨论时间结束，机器人播报：

> 讨论结束，进入投票阶段（90 秒）。请发送：投票 座位号或弃票。官方规则投票后不可改票。

**投票时长：默认 90 秒。**

投票指令（**必须在群里发**）：

```
/vote 3
```

别名：`投票 3`

弃票：

```
/弃票
```

别名：`abstain`、投票阶段发 `跳过` 也等价于弃票

投票的硬性规则：

- **投票后不能改票**。再发一次会被拒绝：「已经投过票，官方规则不允许改票」
- 不填目标会被提醒：「请填写要投票的座位号，例如 /vote 3；弃票请发送"弃票"」
- 出局玩家不能投票
- **所有存活玩家都投完，立刻结算**，不用等满 90 秒
- 迷糊者（笨拙的家伙）有 50% 概率把票投给随机的人，这是他的身份特性

结算可能出现四种结果：

| 情况 | 播报 |
|------|------|
| 有唯一最高票 | 「3号 小明 出局。」并揭示身份 |
| 平票 | 「投票平票（1号、3号），本轮无人出局。」 |
| 全员弃票 | 「本轮没有有效投票，无人出局。」 |
| 和平主义者已发动 | 本轮**不进入投票**，直接跳到夜晚 |

处决完毕后进入下一夜：

> 第 3 夜开始，请查看私聊行动提示。

如果捣乱者发动了双重处决，则本轮会**再投一次**，共出局两人。

### 第 8 步：死亡处理

有人死亡时，机器人会做这几件事：

1. **在群里公布死讯和死因**，例如「昨夜 2号 小刚 被狼人杀害。」「小红 开枪打死了 阿伟。」
2. **揭示身份**（默认开启，可由群配置关闭）
3. **触发死亡连锁**

死亡连锁包括：

| 触发者 | 连锁效果 |
|--------|----------|
| **猎人** | 死亡时可以拉一个人陪葬。私聊会收到菜单，**30 秒**内发送 `猎杀 3`，放弃就发 `跳过`。这期间整局流程会暂停等他 |
| **情侣** | 一方死亡，另一方立刻殉情 |
| **诅咒者** | 被狼人袭击时不死，而是**转化为狼人** |
| **野孩子** | 偶像死亡后转化为狼人 |
| **叛徒** | 所有狼人出局后，他转化为狼人 |
| **学徒预言家** | 预言家出局后继承预言家身份 |
| **狼崽** | 死亡后狼人当夜可以额外杀一人 |
| **智者** | 第一次被狼人袭击时能活下来 |
| **王子** | 首次被投票处决时公开身份并免疫 |

死人之后就只能**旁观**了，不能发言影响游戏、不能投票、不能行动。想中途退出可以在群里发：

```
/flee
```

别名：`逃跑`

注意：**游戏已经开始后 `/flee` 会直接判定你死亡**，只有入场阶段的 `/flee` 才是单纯的退出。

### 第 9 步：胜负判断

每次死亡结算后，机器人自动检查胜负。判定顺序如下：

**只剩 1 人存活**：按这个人的阵营判胜。如果他是替罪羊 / 巫师 / 盗贼 / 分身，则判「无人获胜」。

**只剩 2 人存活**：优先判情侣双赢，其次连环杀手，再次纵火犯，再次教会。

**狼人阵营胜利**：狼人数量 ≥ 其他所有存活者数量。（例外：如果场上还有带子弹的枪手，本次判定会被豁免一轮）

**村民阵营胜利**：场上再没有狼人，也没有教徒。

**替罪羊胜利**：替罪羊被投票处决，他独自获胜——这是他唯一的胜利方式。

**其它独立阵营**：连环杀手、纵火犯、教会各有自己的达成条件。

### 第 10 步：游戏结束

判定出胜者后，机器人在群里播报三样东西：

1. **胜利文案**，例如「狼人吃光了整个村子。」
2. **完整结算名单**（每个人的身份、存活状态、胜负）
3. 给每个人**私聊**一条个人结算：

> 本局结算：获胜阵营为【狼人阵营】。你的身份是【预言家】，状态：出局，结果：失败。

随时可以在群里重新查看结算：

```
/结算
```

别名：`结果`、`result`、`历史`

查看个人历史数据：

```
/统计
```

别名：`数据`、`stats`

想再来一局？直接 `/startgame`。

## 五、卡住了怎么办

### 常见情况

**「我发了指令，机器人没反应」**

先在群里发 `/status`。这条指令在任何阶段都会给你回复，能看到当前阶段、人数、剩余秒数和玩家名单。如果 `/status` 有反应而你的指令没有，多半是：

- 指令发错了地方（夜间行动发到群里 / 群指令发到私聊）
- 你不在这局里
- 当前阶段不允许这个行动

**「夜晚我没收到任何私聊」**

先确认你已经把机器人**加成好友**（见 [1.2](#12-第一次玩先加机器人为好友)）。不是好友时机器人发不出私聊，QQ 会回「无好友关系」。加完好友后，之前卡住的身份牌会自动补发。

已经是好友却仍然没有私聊，那说明你的身份没有夜间技能（村民、酒鬼、王子、市长等），这是正常的，等天亮即可。

**「我想改票」**

改不了。官方规则投票后不可改票，这是刻意保留的设计。

**「群里已经有一局了，我想开新的」**

先让房主或管理员发 `/cancel` 解散，或者等这局结束。一个群同一时间只能有一局。

### 给管理员 / 开发者：运行检测台

如果整局莫名其妙停住了、想知道到底卡在哪一步，可以打开后台运行检测台：

```
http://127.0.0.1:18100/dashboard
```

这是左右栏的只读检测台：左侧切到总览、对局、流程日志或异常投递；右侧先看连接态和服务健康，再看对局诊断卡。页面通过 WebSocket 实时刷新，通道失败后会改轮询。可以看到：

- 网关是否就绪、实时通道状态、失败投递是否大于零
- 所有正在进行的对局、房间状态、当前阶段、当前轮次
- 每名玩家的身份、存活状态、已提交操作、待提交操作
- 投票明细、夜间行动明细
- 机器人主持状态、最近发出的消息、消息投递队列
- 完整流程日志（每一步状态迁移都有记录）
- 停滞检测与异常信息

它会明确告诉你「现在在等谁操作」「为什么还没推进」「下一步会执行什么」。页面上没有改局按钮。

## 六、和官方版本的差异

本项目是官方 `Werewolf for Telegram` 的 QQ 移植版，规则完全对齐，交互方式因平台限制做了等价替换：

| 官方（Telegram） | 本项目（QQ） |
|------------------|--------------|
| 内联按钮点选目标 | 私聊发送文字指令，或分步回复座位号 |
| 昵称显示 | QQ 群拿不到昵称时用「3号」这样的座位号 |
| 多语言切换 | **仅简体中文**，不提供语言切换 |

规则本身（身份技能、夜晚结算顺序、死亡连锁、胜负判定、平衡算法）逐条对齐官方实现，对齐明细见同目录下的 `official-parity-matrix.md` 和 `official-branch-ledger.md`。
