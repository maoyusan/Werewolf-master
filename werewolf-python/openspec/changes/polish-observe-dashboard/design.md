## Context

动机见 `proposal.md` 的 Why；可观察约定见 `specs/observe-dashboard/spec.md`。

当前检测页整页写在 `adapters/web/dashboard.py` 的 `DASHBOARD_HTML`：深色调试控制台风，顶栏把指标做成一排小胶囊，房间卡虽有诊断条，但折叠标题用不可聚焦的点击标题，状态主要靠圆点和变色。数据仍由 `/api/observe` 全量快照与 `/ws/observe` 推送，失败后两秒轮询；页面声明不依赖外部资源。快照间隔一点五秒，房间明细有条数上限。这些后端约束保持不变。

视觉方向取自运维监控检索：深色科技面板、高密度、克制动效。完整毛玻璃适合营销型控制台，不适合长时间盯盘，因此只在右侧顶栏做轻模糊。用户目视后要求改成软件即服务常见的左右栏：左侧固定应用壳，右侧滚动工作区。

## Goals / Non-Goals

**Goals:**

- 在同一地址用同一套只读数据，把页面改成可扫描的企业检测台
- 用页面内层叠样式变量固定色板、间距与字体阶，避免散落魔法数
- 把折叠、连接态、错误摘要改成键盘与辅助技术可用
- 用静态断言锁住「无外链、有地标、状态不只靠颜色」

**Non-Goals:**

- 拆成独立前端工程，或引入构建链、组件库、外链字体
- 浅色主题、登录鉴权、按角色隐藏字段
- 改 `/healthz`、`/readyz` 的字段或状态码
- 每次快照额外探测数据库健康（避免给一点五秒刷新加库压）
- 新增写接口或在页面上操作对局

## Decisions

### 1. 继续内嵌整页，不用新前端栈

检测页继续由 `_dashboard_page` 返回 `DASHBOARD_HTML`。样式用页面内自定义属性，脚本保持原生。不引入构建步骤，也不把页面拆到独立静态目录。

**理由：** 现有部署是单进程直接出页，运维环境常不能访问外网；改栈会把「断网外链仍能渲染」变成额外负担。  
**备选：** 上组件库或外链字体 → 违反自包含，且与当前「零外部资源」注释冲突。

### 2. 深色科技色板，毛玻璃只用于顶栏

令牌（实现时写入 `:root`，组件里禁止再写裸十六进制）：

| 用途 | 色值 |
|------|------|
| 页面底 | `#0F172A` |
| 卡片 | `#1B2336` |
| 次级面 | `#1E293B` |
| 主文字 | `#F8FAFC` |
| 正文次级 | `#CBD5E1` |
| 元信息 | `#94A3B8` |
| 边框 | `#475569` |
| 正常/强调 | `#22C55E` |
| 警告 | `#D29922`（沿用现有诊断黄，保证对比） |
| 错误 | `#EF4444` |
| 焦点环 | `#FFFFFF` |

正文次级不用过浅的灰，以保证普通字号对比度不低于四点五比一。元信息只用于大号标签或非唯一状态。顶栏可用半透明底加约十二像素模糊；卡片保持实底，避免大面积模糊造成对比与性能问题。

**备选：** 全页毛玻璃或浅色事故页色板 → 前者伤对比与性能，后者与现有暗色盯盘习惯相反。

### 3. 系统字体，不用外链字库

界面字体：`system-ui`、`Segoe UI`、`PingFang SC`、`Microsoft YaHei`。等宽：`ui-monospace`、`Cascadia Mono`、`Consolas`。字号阶：十二、十四、十六、二十。正文十四，元信息十二，标题二十。检索建议的外链等宽字体只作气质参考，不写入页面。

### 4. 信息架构做成左右栏应用壳

宽屏采用软件即服务后台常见的左右布局，而不是把指标和房间堆在一条顶栏里：

```
左侧应用壳：品牌「狼人杀 · 运行检测台」+ 页内分区导航（总览、对局、流程日志、异常投递）+ 网关与最近投递摘要
右侧顶栏：页面一级标题 + 单一连接态（role=status）+ 快照时间
右侧工作区：错误摘要、服务健康条、总览指标卡片、对局诊断卡、全局流程日志、异常投递
```

导航只做页内锚点，不拆成多页、不另打 `/healthz`。健康条只复用快照里已有字段（如网关就绪、失败投递数）和页面自己的连接态。

窄视口下左侧壳改为顶部横向导航，右侧分区单列纵向排列，根层不得出现整页横滚。

折叠从不可聚焦标题改为按钮，带 `aria-expanded`。默认展开「诊断相关」的系统事件与异常投递，玩家表默认展开，投票与夜间行动在无数据时可默认收起。

**备选：** 继续用单列顶栏堆指标 → 用户已明确否定，扫读仍像调试控制台。

### 5. 图标用内联矢量，语义跟文字绑定

状态图标按轮廓风格内联：正常用对勾圆、提示用信息、警告用三角、错误用叉圆、等待用时钟。装饰性图标加 `aria-hidden`；独立表达状态的图标必须旁边有中文标签。禁止表情符号当图标。

### 6. 一处实时区，错误用警告角色

连接态容器使用 `role="status"` 且 `aria-atomic="true"`，播完整中文句子（例如「实时连接已建立」），不要只播数字。指标数字变化不另开实时区，避免互相抢播。观测错误写入顶部 `role="alert"` 摘要；首次出现时可把焦点移到该摘要，之后刷新同一错误不再反复夺焦。

右侧粘性顶栏配合 `scroll-padding-top`，避免焦点被顶栏完全挡住。

### 7. 动效只做颜色与透明度

过渡限定在一百五十到二百毫秒的颜色、透明度、阴影。不动画宽高。`prefers-reduced-motion: reduce` 时过渡时间为零，直接终态。

### 8. 测试锁结构，不锁截图像素

新增只读测试：从应用取出 `/dashboard` 正文，断言标题含「检测台」或等价约定词、存在一级标题、连接态带状态角色、折叠为按钮、源码不含外链字体或外链脚本主机。现有快照接口测试若已有则不改契约。不引入浏览器截图对比。

## Risks / Trade-offs

- **[风险] 内联超文本继续膨胀，难审阅** → 缓解：样式按令牌分区注释；不把脚本拆文件，以免破坏「单响应自包含」
- **[风险] 次级灰对比仍不够** → 缓解：正文次级固定为高对比灰；元信息不得单独承担状态
- **[风险] 大表在窄屏内部滚动被误认为整页可横滑** → 缓解：只给表格包装器设横向滚动，根层 `overflow-x: hidden`
- **[取舍] 健康条不含数据库探测** → 机器探测仍看 `/healthz`；检测页优先网关与投递，避免刷新打库
- **[取舍] 不做浅色主题** → 减少一套对比验收；若以后要做，只加数据属性换令牌，不改结构

## Migration Plan

1. 只发布新的 `DASHBOARD_HTML` 与文档用语，路由与端口不变
2. 重启服务后打开原地址目视分区、连接态、空态与一局诊断卡
3. 用键盘走完折叠与错误摘要
4. 回滚：还原该文件中的页面字符串并重启，无需迁库
